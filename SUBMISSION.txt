Visual reverse-engineering assignment — North Atlantic right whale abundance

Public page: https://Nicoleluu.github.io/ocean-whales-visual-recreation/
GitHub repository: https://github.com/Nicoleluu/ocean-whales-visual-recreation

Recreates NOAA's North Atlantic right whale population chart using the original data. Direct chart interactions include draggable year comparisons with absolute/percentage change and playback that traces the original line through time. Other controls include pointer inspection, time-range filtering, uncertainty/average toggles, and reset. Original chart screenshot, source CSV files, HTML/CSS/JavaScript, attribution, and process notes are included in the repository.
